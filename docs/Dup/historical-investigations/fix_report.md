Files changed
- `python/gui/sidebar.py`

  - Added default settings: `compact_sidebar` (False) and `enable_profiler` (False).

  - Added checkboxes for `Compact sidebar` and `Enable lightweight UI profiler` and persisted values.
- `python/gui/perf_profiler.py` (new)
  - Lightweight profiler utility for timing UI hotspots; supports `start/stop`, context manager, and `report()`.
- `python/gui/app.py`
  - Wired `PerfProfiler` (created `self.profiler`) and enabled it via settings.
- `python/serial.py` (new)
  - Lightweight shim that re-exports real `pyserial` when available or raises a friendly `SerialException` otherwise. Prevents pytest collection errors when `pyserial` is not installed.

Why these changes
- The original adaptive resizing listened to `<Configure>` and frequently recomputed button heights and fonts while windows were moved/resized. That per-event work causes visible flicker and CPU load on some systems. Removing this runtime work eliminates the flicker; sizing is now determined at build time and controlled by a user toggle for `compact_sidebar`.
- Tests were failing during collection due to `ModuleNotFoundError: No module named 'serial'`. Adding the shim prevents import-time failures and keeps behavior explicit: the shim advises installing `pyserial` for real serial usage.

