# Generated Documentation

This directory contains generated inventories, snapshots, and forensic summaries produced at particular points in the repository history.

Generated documents are useful for audit and comparison, but they are not the authority for current behavior. Before using a claim operationally, verify it against current source, focused tests, and the canonical documents linked from `docs/README.md`.

Each generated file should record its source commit or generation date when that information is available. Stale generated output should be regenerated or clearly retained as historical evidence; it should not be silently presented as a live architecture specification.
