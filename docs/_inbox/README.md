# Documentation Image Inbox

Place new, unsorted images in this folder for review.

Images are sorted after checking their visual content and checksum against the canonical folders:

- UI screenshots: `../UserGuide/images/`
- Hardware and wiring photos: `../Hardware/images/`
- Diagrams: `../Architecture/images/`
- Unclear or unrelated images remain here until reviewed

Sorted images should receive descriptive filenames, and any documentation links should be updated in the same change.
