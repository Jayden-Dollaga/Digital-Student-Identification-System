🛠️ TROUBLESHOOTING
-----------

Can't find module?
  → cd to project root first
  
Settings not saving?
  → Check data/ folder has write permissions
  
GUI won't launch?
  → pip install customtkinter

Toggles don't stick?
  → Check data/settings.json exists
  → Run test_settings_toggles.py to verify
