THE 4 TOGGLES YOU CAN TEST
==========================

1. Auto-Reconnect
   - Controls automatic ESP32 reconnection
   - ON = auto reconnect when disconnected
   - OFF = manual reconnect required

2. Auto-Detect ESP32  
   - Controls automatic port detection on startup
   - ON = auto-find ESP32
   - OFF = manual port selection

3. Compact Sidebar
   - Controls button display style
   - ON = icons only (shorter buttons)
   - OFF = full text labels

4. Enable Profiler
   - Controls performance tracking
   - ON = track timing data
   - OFF = no tracking

TROUBLESHOOTING
===============

Error: "ModuleNotFoundError"
  → Make sure you're in the project root directory
  → cd to the project folder before running

Error: "Settings not saving"  
  → Check that data/ folder exists and is writable
  → Look for data/settings.json file

GUI won't open:
  → Install customtkinter: pip install customtkinter
  → Verify all dependencies with: pip install -r requirements.txt

Toggles don't stick:
  → Check data/settings.json exists
  → Look at file permissions
  → Run: python tests/test_settings_toggles.py to verify storage works
