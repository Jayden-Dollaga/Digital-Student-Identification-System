INTERACTION FLOW
═══════════════════════════════════════════════════════════════════════════════

1. GUI OPENS
   ├─ Load settings from data/settings.json
   ├─ Set checkboxes to saved values
   └─ Display status "Ready"

2. YOU TOGGLE A CHECKBOX
   ├─ Checkbox changes state (checked ↔ unchecked)
   ├─ "Active Toggles" counter updates (4/4 → 3/4 etc)
   └─ Log shows "[14:23] Toggle changed"

3. YOU CLICK "SAVE SETTINGS"
   ├─ Read all checkbox values
   ├─ Write to data/settings.json
   ├─ Show status "✓ Settings saved"
   ├─ Log shows "[14:24] ✓ Settings saved successfully"
   └─ Status resets to "Ready" after 2 seconds

4. YOU CLOSE AND REOPEN GUI
   ├─ Load settings from data/settings.json
   ├─ Your toggles are restored!
   └─ Everything persists

WHAT HAPPENS IN THE BACKGROUND
═══════════════════════════════════════════════════════════════════════════════

When you save:

  Python Code:
    new_settings = {
        "auto_reconnect": True/False,
        "auto_detect_serial": True/False,
        "compact_sidebar": True/False,
        "enable_profiler": True/False,
    }

  Saved to JSON:
    {
        "com_port": "COM3",
        "baud_rate": 115200,
        "cooldown": 10,
        "theme": "dark",
        "auto_reconnect": true,
        "auto_detect_serial": false,
        "compact_sidebar": true,
        "enable_profiler": false
    }

  File Location:
    data/settings.json ← Check this file!

  On Restart:
    1. Load data/settings.json
    2. Parse JSON
    3. Update app components
    4. Restore UI state
